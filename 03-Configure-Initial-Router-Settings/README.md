# Lab 03: Configure Initial Router Settings

## Overview
This lab focuses on the initial configuration and security of a Cisco router using Cisco Packet Tracer. It covers basic router settings, password protection, login banners, and configuration management.

## Objectives
- Verify the default router configuration.
- Configure the router hostname.
- Secure console access using a password.
- Configure privileged EXEC passwords.
- Encrypt plaintext passwords.
- Configure a Message of the Day (MOTD) banner.
- Verify the running and startup configurations.
- Save the configuration to NVRAM.
- Explore flash storage and back up the startup configuration.

## Network Devices
- Cisco Router R1
- PC-A (Console Access)

## Configuration Tasks
- Set the router hostname to R1.
- Configure the console password.
- Configure the enable password and enable secret.
- Enable password encryption.
- Configure an MOTD banner to warn unauthorized users.
- Verify the configuration using Cisco IOS show commands.
- Save the running configuration to startup configuration.

## Security Features
- Console password protection.
- Privileged EXEC mode security.
- Encrypted enable secret.
- Password encryption using `service password-encryption`.
- MOTD banner for unauthorized access warnings.

## Verification Commands
- `show running-config`
- `show startup-config`
- `show flash`
- `copy running-config startup-config`

## Key Skills Learned
- Cisco IOS CLI navigation.
- Basic router configuration.
- Password protection and encryption.
- Understanding running-config and startup-config.
- Understanding NVRAM and flash storage.
- Saving and verifying router configurations.

## Tools Used
- Cisco Packet Tracer
- Cisco Router
- Cisco IOS CLI
